# Cinematic Lab — Golden Intro

Интерактивное 3D-интро на React и Three.js. Для работы нужен браузер с поддержкой WebGL. Интро и экспорт работают без звука.

## Запуск

```sh
npm ci
npm run dev
```

Для проверки типов и production-сборки:

```sh
npm run typecheck
npm run build
npm run preview
```

## Медиа и настройка

Десять исходных видео из `arena.ai/circle/video` автоматически загружаются из `public/videos` в порядке имён на Диске. Для просмотра и экспорта дождитесь загрузки. При развёртывании сохраняйте папку `videos` рядом с `index.html`: видео не встроены внутрь HTML. Чтобы заменить видео, сначала нажмите «Очистить слоты», затем выберите фото или видео кнопкой либо перетащите их на окно. Файлы занимают свободные слоты по порядку. Данные остаются в браузере и никуда не отправляются. Неподдерживаемые и повреждённые файлы не занимают слоты.

После запуска используйте таймлайн внизу: пауза, воспроизведение, перемотка и метки для перехода к кадрам. Перемотка ставит анимацию на паузу; нажмите воспроизведение, чтобы продолжить.

Название бренда и исходные URL медиа задаются в `src/intro/config.ts`. Короткие клипы зацикливаются на время показа панели. В экспортируемом ролике нет служебных надписей, остаётся только финальная подпись бренда. В интро есть яркая вспышка и движение камеры.

## Покадровый экспорт

Кнопка «Смотреть интро» запускает анимацию; отдельная кнопка «Экспортировать MP4» доступна до, во время и после просмотра. Экспорт запускается только по нажатию. Готовый MP4 открывается во встроенном плеере, откуда его можно скачать. Экспорт рассчитывает кадры последовательно с фиксированными временными метками (1920 × 1080, 60 fps) и собирает MP4 с H.264 без аудиодорожки. Скорость экспорта зависит от устройства и может быть значительно ниже скорости воспроизведения. Звук загруженных видео также не используется.

Нужен браузер с поддержкой WebCodecs и кодирования H.264 1080p60 (уровень 4.2), например совместимая версия Chrome или Edge. Не все браузеры и устройства поддерживают эти кодеки. На устройствах с ограниченной памятью или слабым GPU экспорт может завершиться ошибкой. Не закрывайте вкладку до завершения; при ошибке, пропущенных кодировщиком кадрах или отмене неполный файл не сохраняется. Встроенные видео декодируются через браузер с позиционированием на нужный момент; качество и точность зависят от поддержки исходного кодека браузером. Для экспортируемых роликов с удалённого URL необходим корректный CORS.

`npm test` проверяет непрерывность временных меток экспорта. Реальный экспорт, воспроизведение MP4 и синхронизацию нужно дополнительно проверять в целевых браузерах и на устройствах.
